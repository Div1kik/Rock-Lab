# PROJECT_RULES.md — Конституция проекта «Rock Lab» (Easy Dopamine Games)

## 1. Стек и целевые площадки
- **Движок:** Phaser 3 (подключение через CDN, чистые ES-модули `import/export` без npm/Webpack/Vite).
- **Целевые платформы:** Яндекс Игры, ВКонтакте (VK Mini Apps), мобильный и десктопный веб (с возможностью упаковки в Capacitor/Cordova под мобильное приложение).
- **Экран и адаптив:** Вертикальная (портретная) ориентация `480×800`, `Phaser.Scale.FIT`, автоцентрирование.
- **Графика и стиль:** Уютный детализированный 2D / стилизованный пиксель-арт в тёплой, некислотной палитре. Все растровые ассеты — сразу в `.webp` (фоны не выше 1920px). UI, шкалы, трещины, частицы и эффекты — процедурно через Canvas/Graphics.
- **Звук:** Web Audio API (`AudioManager.js`) — процедурные тактильные звуки (шуруповёрт, гул пресса, хруст породы, щелчки датчиков, штамп отчёта) + мягкий фоновый эмбиент с обязательным глушением при рекламе и сворачивании вкладки.

## 2. Архитектура и контракты
- **Единый адаптер SDK (`src/utils/PlatformSDK.js`):** Изолирует вызовы рекламы (`Rewarded`, `Interstitial`) для VK Bridge / YaGames / Web. Сцены никогда не вызывают SDK напрямую.
- **Единое хранилище (`src/utils/Storage.js`):** Ключ `rocklab_save_v1`. Хранит: `money`, `reputation`, `completedContracts`, `labLevel` (1..5), `upgrades` (`drill`, `press`, `sensors`, `loader`), `soundEnabled`.
- **Реестр испытаний (`src/data/tests.js`):** Модульная архитектура стендов (расширяемая новыми испытаниями в обновлениях).

## 3. Структура проекта
- `index.html` — точка входа, шрифты, запрет тач-скролла.
- `PROJECT_RULES.md` — правила проекта (вставляется в начало каждого нового чата).
- `src/main.js` — инициализация Phaser (`480×800`, `FIT`).
- `src/data/contracts.js` — генератор заказов, породы грунтов, сюжетные описания и расчет реальной прочности.
- `src/data/upgrades.js` — уровни лаборатории и прокачка оборудования.
- `src/utils/PlatformSDK.js` — адаптер платформ (VK / Яндекс / Web).
- `src/utils/Storage.js` — сохранения и экономика.
- `src/utils/AudioManager.js` — процедурный звук инструментов и фоновый эмбиент.
- `src/scenes/BootScene.js` — загрузка ассетов, генерация процедурных текстур.
- `src/scenes/MenuScene.js` — главный экран лаборатории (визуал текущей лабы + переход к заказам и улучшениям).
- `src/scenes/ContractsScene.js` — доска заказов (выбор контракта).
- `src/scenes/UnpackScene.js` — этап 1: вскрытие ящика шуруповёртом и извлечение кернов.
- `src/scenes/TestScene.js` — этап 2: прохождение назначенных мини-игр (сжатие, сдвиг, камера).
- `src/scenes/ReportScene.js` — этап 3: итоговый протокол, вынесение инженерного вердикта и катсцена результата.
- `src/scenes/UpgradeScene.js` — улучшение оборудования и интерьера лаборатории.

## 4. Железные правила для ИИ-ассистента
1. **Не ломать рабочее:** Не переписывать соседние сцены и не менять сигнатуры публичных методов без согласования.
2. **Полные файлы:** Если в файле меняется более 15 строк — выдавать файл целиком, без сокращений.
3. **Сначала контракт, потом код:** Перед созданием новой сцены сверяться с ключами `Storage.js` и методами `AudioManager.js`.
4. **Проверка контекста:** Если нужен актуальный код соседнего файла — сначала запросить его.
5. **Лаконичность:** Отвечать по делу, без воды.
